# Output Contract

All output paths below are relative to the external run directory, never to the skill package.

## Single Run

Every standalone or formal run must contain:

| Artifact | Required content |
|---|---|
| `equity_curve.csv` | timestamped account equity and cost-aware metrics |
| `equity_curve.png` | rendered equity curve |
| `trades.csv` | entry, exit, direction, price, quantity, costs, and PnL |
| `report.md` | assumptions, results, warnings, and audit status |
| `run_manifest.json` | strategy, parameters, data identity, hashes, engine, and timestamps |

Formal engine HTML/TXT reports are copied into the same run directory when generated.

## Comparison

Governed comparisons must contain:

- `compare_curve.csv`
- `compare_equity.png`
- `compare_summary.md`
- `compare_manifest.json`

The comparison manifest must record the input run directories, bars hashes, adjustment modes,
strategy identities, and cost assumptions.

## Stitched Results

Governed stitched results must contain:

- `stitched_curve.csv`
- `stitched_curve.png`
- `stitched_summary.md`
- `stitched_manifest.json`

Stitched results must be generated by a governed script from run artifacts. They must not be
hand-built from copied CSV fragments.

## Manifest Minimum

At minimum, `run_manifest.json` records:

- input symbol, frequency, date range, and session policy;
- strategy version and strategy file hash;
- adjustment mode and frozen dataset manifest path;
- per-source bars hashes and combined dataset hash;
- initial capital, quantity, contract multiplier, margin, fee schedule, and slippage;
- execution convention and artifact paths;
- warnings and audit status.
